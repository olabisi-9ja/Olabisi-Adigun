Full-stack Web Development.

I build web applications that are quick to load, easy to use and boring to operate, in the best sense of boring.

I take products from design to deployment: a React or Next.js frontend, a Node.js API, PostgreSQL for data, and the plumbing that makes it production-grade, CI, hosting, analytics and error monitoring.

Approach

  • Scope. Define the smallest shippable version and the milestones after it.
  • Build. Small, reviewed increments with a deployable build at every step.
  • Harden. Accessibility, performance budgets, security headers and tests.
  • Ship. CI/CD, hosting, monitoring and a handover your team can run with.

Deliverables

  • A production web application with CI and hosting configured.
  • Documentation: setup, architecture and runbooks.
  • Performance and accessibility checks (Lighthouse, keyboard, contrast).
  • Optional maintenance and iteration retainer.

Typical timeline

Four to twelve weeks for an MVP, depending on integrations.
